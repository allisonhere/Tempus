Paste the output of  /tempus gearstats  into a new .txt file here (one file per character, any name), for
example druid-22.txt. Then run:  python3 tools/gen_gearadvisor.py stats
It lists every stat name seen, which have a weight, and which are new, so the mapping in
tools/gearadvisor/statmap.json can be corrected. Chat colour codes and the "Tempus:" prefix are ignored.
